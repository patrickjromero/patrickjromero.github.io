# personal-site

Patrick Romero's personal website — single-page static site (HTML/CSS/JS, no build step).

## Structure
- `index.html` — hero, About, Resume, Projects, Contact + nav with Projects/Business dropdowns
- `styles.css` — minimalist theme, deep navy accent (#1f3a5f), mobile-responsive
- `script.js` — mobile nav + dropdown behavior
- `assets/` — headshot + the three resume PDF editions (bundled so downloads always work)

## Deploy
Enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main` / root).
Live URL will be `https://HelloFold.github.io/personal-site/`.

## Notes
- No phone number or street address on the public site (privacy).
- "Business" nav dropdown links to https://hellofold.studio.
- Site copy source of truth: Notion page "Personal Website".
